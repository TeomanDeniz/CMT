CMT (C MAXIMUM TENSION) FOR NOTEPAD++

NOTEPAD++ CAN'T LOAD A SECOND C GRAMMAR, BUT ITS C AND C++ LEXERS HAVE
"USER-DEFINED KEYWORDS" BOXES. PASTE THE TWO LISTS BELOW INTO THEM:

  1. Settings > Style Configurator...
  2. Language: C
  3. Style: INSTRUCTION WORD -> paste LIST 1 into "User-defined keywords"
  4. Style: TYPE WORD        -> paste LIST 2 into "User-defined keywords"
  5. Save & Close. Repeat steps 2-5 with Language: C++

(.INL FILES: Settings > Style Configurator > Language: C > "User ext." -> inl)
