## Abstract

With these functions, you're able to move and get values from the Intel CPU register R10 and stack with different data sizes and archs.

Using `GET_R10` or `SET_R10` on a non-Intel CPU will cause an error on compiling time.

> ⚠️ Note
> 
> On Intel 32-BIT and 64-BIT, this header will throw an error.

----

### GET_R10

```c
#define GET_R10(VARIABLE)
#define get_r10(variable)
```

Sets the value of `R10` register holding to your variable.

Example:

```c
long long test = 0;

volatile_function_that_sets_r10_to_42();

get_r10(test);

printf("%d\n", test); // 42
```

----

### SET_R10

```c
#define SET_R10(VALUE)
#define set_r10(value)
```

Sets the `R10` register's value to given value or variable.

**Examples**:
```c
set_r10(42);
```

```c
long long value = 42;

set_r10(value);
```
